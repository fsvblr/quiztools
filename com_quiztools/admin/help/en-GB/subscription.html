QuizTools: Creating and editing a subscription

On this page, you can create a new subscription to a quiz or learning path, or edit an existing one.

General tab

Basic subscription settings are configured here.

Title
The name of the subscription. It is shown in the list of subscriptions and used when assigning a subscription.
Status
Subscription status toggle: enable/disable.
Payment method

Select the method by which you will sell access to this subscription.

By default only Manual is available. This option means that the subscription is handled manually: an order is created in the administrator area for the selected user, and you yourself track payment for this subscription and manually change its status to Confirmed.

If a third-party e-shop component is installed on the site (for example, HikaShop or VirtueMart) and the corresponding QuizTools payment plugin is enabled, then the choice of paying through that shop is added to this field.
Don't forget to configure the appropriate QuizTools payment plugin.

When a payment method other than Manual is selected, an additional required field [E-shop name] Product appears.

[E-shop name] Product

This field is shown only when the selected payment method is not Manual. It is mandatory in that case.

The field contains a list of products that exist in the selected e-shop component. You need to match one of these products with the subscription being created. The selected product is the one that the site user will purchase on the front-end to gain access to this subscription.

One product of a third-party e-shop component can be linked to only one QuizTools subscription. If a product is already used in another subscription, it will disappear from the selection list for the current subscription.

Create the product in the third-party e-shop component before creating the subscription in QuizTools. We recommend giving the product the same name as the subscription so that users are not confused.

Type
Select what the subscription grants access to: a single quiz or a learning path.
Quiz
Visible when the type is Quiz. Select the quiz to which this subscription provides access.
Learning path
Visible when the type is Learning path. Select the learning path to which this subscription provides access.
Access type
Choose how access duration is defined: by a fixed number of days or by an exact date range.
Number of days of access
Visible when access type is X days. The number of days a user will have access after the order is confirmed.
If 0 (zero) is selected, this means "lifetime" access—an unlimited number of days.
From
Visible when access type is Period of days. Start date and time from which access is available.
To
Visible when access type is Period of days. End date and time until which access is available.
If an end date and time for access are not selected, then access is not limited by time.
Attempts
The number of attempts allowed for the quiz or learning path linked to this subscription.
If 0 (zero) is selected, this means an unlimited number of attempts.

Publishing tab

The Publishing tab shows service information about the record:

  • ID — unique number of the subscription in the database;
  • Created — date and time when the subscription was created;
  • Created by — user who created the subscription;
  • Modified Date — date of the last change;
  • Modified by — user who last changed the subscription.

These fields are filled in automatically and usually do not require manual changes.

Payment processing and front-end orders

When an order is created for this subscription, the user can see it on the front-end in the list of orders. If the order status is Confirmed, and if the order has not yet expired (based on its End and Attempts characteristics), then that order is available for the user to take the quiz or learning path.

For payments through a third-party e-shop component, after the user pays for the product, the subscription status automatically changes to Confirmed, and the subscription becomes available on the front-end.

For the manual payment method, the subscription status must be changed to Confirmed manually by an administrator after payment has been received.

Saving changes

Before saving, fill in at least the required fields Title and Payment method. If the selected payment method is not Manual, the [E-shop name] Product field also becomes required. After configuring the subscription fields, click Save or Save & Close on the toolbar.

Once a subscription has been created (after the initial save), the "Payment method" and "[E-shop name] Product" fields become non-editable.
