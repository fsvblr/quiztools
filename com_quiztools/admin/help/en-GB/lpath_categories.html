QuizTools: Learning Paths Categories

The Learning Paths Categories list is used to find, add, and edit learning paths categories.

Categories are used to organise Learning Paths for ease of management and display. They can be organised into tree-like structures like file systems. All Learning Paths must be assigned either to a parent Category or a child Category.

Learning Paths categories are based on the default, built-in category functionality. You can find more information about the list of categories in the help documentation on the Joomla article categories page.
