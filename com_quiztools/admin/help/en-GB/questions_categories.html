QuizTools: Questions Categories

The Questions Categories list is used to find, add, and edit questions categories.

Categories are used to organise Questions for ease of management and display. They can be organised into tree-like structures like file systems. All Questions must be assigned either to a parent Category or a child Category.

Questions categories are based on the default, built-in category functionality. You can find more information about the list of categories in the help documentation on the Joomla article categories page.
