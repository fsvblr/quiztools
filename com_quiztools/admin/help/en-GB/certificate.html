QuizTools: Creating and editing a certificate

This page is used to create a new certificate for a quiz or edit an existing one.
A certificate can be assigned to a specific quiz in its settings so that it is issued to participants after successful completion.

General tab

Basic certificate settings are configured here.

Note
A short internal note about the certificate. Pay attention to the information included here.
Title
The name of the certificate. It is shown in the list of certificates and used when selecting a certificate in quiz settings.
Status
Determines whether the certificate is published. Only published certificates can be used in quizzes.
Image
Selection of the image file (background) from which the certificate will be generated. The image is in PNG or JPG format.
Upload image
Field for uploading your own image from your computer. It is available only to users with the core.manage permission for the QuizTools component. If this permission is missing, a message about insufficient rights is shown instead of the upload field, but you can select an existing file in the “Image” field.
Certificate fields
Variables that will be inserted into the certificate are configured here: user name, result, completion date, and others.
Each subform row is one text line:
  • When a new row is added in the subform, a new line “Edit this text” appears in the upper-left corner of the preview area.
  • When you hover over this line you can move it to the desired position on the certificate image.
  • When you click on this line it becomes editable, and you can change the text to your own.
  • When you move a text line or change its content, the corresponding data in the subform fields is updated automatically.
  • In the subform fields you can change the font, font size, and font color for the text line.
The preview area below the field list shows an interactive layout of the certificate. Fields can be moved directly on this canvas, after which their positions are saved together with the certificate.

Publishing tab

The Publishing tab shows service information about the record:

  • ID — unique number of the certificate in the database;
  • Created — date and time when the certificate was created;
  • Created by — user who created the certificate;
  • Modified Date — date of the last change;
  • Modified by — user who last changed the certificate.

These fields are filled in automatically and usually do not require manual changes.

Saving changes

Before saving, fill in at least the required fields “Title” and “Image”. If the “Upload image” field is available, you can upload the certificate background file. Or select it from already uploaded files via the “Image” field. After configuring the certificate fields, click “Save” or “Save & Close” on the toolbar.

The "Preview" button on the toolbar.

Clicking this button will display a pop-up window previewing your certificate with the saved text data.
Since this is the admin panel, the shortcodes will be displayed without the actual data. You can generate the certificate with the actual data in the "Results" section (admin or front-end).
