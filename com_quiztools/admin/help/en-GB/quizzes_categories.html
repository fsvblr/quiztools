QuizTools: Quizzes Categories

The Quizzes Categories list is used to find, add, and edit quizzes categories.

Categories are used to organise Quizzes for ease of management and display. They can be organised into tree-like structures like file systems. All Quizzes must be assigned either to a parent Category or a child Category.

Quizzes categories are based on the default, built-in category functionality. You can find more information about the list of categories in the help documentation on the Joomla article categories page.
